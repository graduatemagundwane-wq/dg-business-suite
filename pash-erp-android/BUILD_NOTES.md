# PASH Auto ERP Android Build

This isolated branch builds only the Android application shell using PASH Auto logo. The app requires PASH Auto's separate live HTTPS ERP server and does not contain client records, backend secrets or demo data. Do not merge into DG Business Suite.

Install the generated test APK only after verifying its GitHub Actions build status. First launch prompts for the secure PASH Auto ERP server URL. Do not confuse an APK launcher with a hosted backend or verified Google Drive backup.
