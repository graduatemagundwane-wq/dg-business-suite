# Android build and test — PASH Auto Operations

The deliverable in this package is **Android app source**, not an APK. The cloud
build configuration is prepared but no signing credentials, EAS project, network
API, or connected device has been verified. Do not count as production accepted.

## Required prerequisites

1. Isolated PASH Operations HTTPS API deployed against the PASH Operations
   Postgres database after migrations `001` through `004`.
2. Create a real organization ID for PASH Auto with owner/employee accounts.
3. Install Node 22 and Android SDK or use an Expo EAS account with signing.
4. Put `EXPO_PUBLIC_API_URL` and `EXPO_PUBLIC_ORGANIZATION_ID` in the build
   environment. The URL is not a secret; NEVER put the JWT secret or database URL
   in the APK.
5. Install dependencies: `npm install`; validate with `npx tsc --noEmit` and
   `node --test tests/*.test.js`.
6. QA APK via `npx expo prebuild --platform android` then Android Gradle
   `assembleDebug`, or EAS `eas build -p android --profile qa` after EAS setup.
7. Production Google Play AAB: EAS `eas build -p android --profile production`
   after company signing credentials are configured and secured.

## Required acceptance on real Android devices

- Cold-start/login; invalid login; password change; logout/revocation; background
  lock, biometric opt-in with enrolled strong biometrics; account suspension.
- Each role and combined-role account: no unauthorized records or actions.
- Customer check-in, assigned technician jobs, DSG and battery reporting,
  parts issue/receipt, quotations, customer approvals, QA sign-off, attendance.
- QR/VIN/SKU scan with camera permission granted/denied; orientation,
  short and tall screens, keyboard and network errors; no crash under low memory.
- Wrong-tenant and wrong-employee access; duplicate job/stock transactions.
- Offline connectivity: app must **not** falsely report a server write as saved.
  The current implementation does not provide a durable offline write queue.
- Academy instructor publishing, student exams, completion/certification.
- QA logging, storage permissions, backup and restore, performance and security
  review; mobile distribution signing and update strategy.

*The above are requirements, not claimed passes.*
